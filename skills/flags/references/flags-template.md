## Usage Guide

### Creating FLAGS.md

1. Create `.claude/FLAGS.md` at project root
2. Copy and paste the template above
3. Replace `{project-name}` with project name
4. Update MCP/Plugin Flags sections as needed

### Flag Priority

```
Safety > Quality > Workflow > Skill > Agent > Output
```

Higher priority flags are applied before lower priority ones.

### Adding Custom Flags

Add flags to the appropriate section when using MCP servers or additional plugins.

```markdown
## 7. MCP Flags

| Flag | MCP Server | Description |
|------|------------|------|
| `--context7` | context7 | Library documentation lookup |
| `--playwright` | playwright | Browser automation |
```
